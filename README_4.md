# Póster de campaña · SPAN 2156 · Fall 2026

- `index.html`: página de inicio con los dos enlaces.
- `poster/`: hoja de asignación y lista de voces.
- `deck/`: presentación interactiva del taller (teclas: ← →, N notas, F pantalla completa, Ctrl/Cmd+P para PDF).

## Publicar en GitHub Pages

1. Crea el repositorio **span2156-poster** (público) y sube el contenido de esta carpeta, manteniendo las subcarpetas.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. En un minuto estará en https://lisola628.github.io/span2156-poster/

## Moodle

Pega `SPAN2156_Poster_Moodle_bloque.html` en la sección (Edit section → Source code). Sus botones apuntan a las direcciones de arriba; si usas otro nombre de repositorio, cámbialas.
